# Changelog

## [1.0.0] - 2026-05-19

### Added
- Initial open source release (international version)
- Bible projection with KJV built-in
- Song/hymn projection with slides
- 5 public domain hymns built-in
- Custom backgrounds (images and video)
- Multi-display support (projection, live, stage, external)
- Countdown timer and clock display
- Screen sharing
- `.jydata` data pack import system for additional Bibles and songs
- Bilingual UI support (zh-CN / zh-Hant / en)
- Playlist creation and playback
- macOS, Windows, and Linux support
